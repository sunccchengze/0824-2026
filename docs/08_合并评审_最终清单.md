3. 深限功率（目标 < 可达最小值）当前如实报偏差；如需真限发需引入停机/变桨维度，超出本轮演示模型粒度。
4. 移动竖屏为等比缩放信箱方案，非重排自适应；如需正式移动版，另立设计。
